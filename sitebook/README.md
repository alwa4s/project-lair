# SiteBook

The lair of my sysadmin labs. Look if you dare!

A technical documentation resource for a virtualized enterprise network built across the labs of **NSSA-221: System Administration I** at RIT Dubai. It records the configuration, deployment steps, and troubleshooting notes for each service so the environment can be reproduced and maintained.

## Environment

- **Platforms:** Windows Server 2022, Windows 11, Rocky Linux, pfSense (router/firewall)
- **Identity & Network Services:** Active Directory, Group Policy, DHCP, DNS
- **Storage & File Services:** RAID 1/5, Samba, FTP, NFS
- **Automation:** Bash and cron scripts for rsync backups, disk monitoring, and network ping checks

## What's Inside

- Network topology and device configuration
- Windows Server and Active Directory setup (organizational units, users, GPOs)
- RAID and partition configuration on the Linux storage server
- File transfer and sharing services (Samba, FTP, NFS)
- Appendix of PowerShell and Linux commands and the Bash scripts used

## Notes

- Built and tested in an isolated virtual lab environment (RLES) for coursework.
- Hostnames, domains, and addresses are lab-only examples.
